Core Capabilities

Built for serious
financial analysis.

Not a whiteboard tool. Not a diagram maker. Arbor is a live calculation engine wrapped in a premium interface — built for analysts, advisors, and investors.

⬡
Interactive Decision Tree
Build any depth of branching decisions. Drag nodes, reassign probabilities, rename outcomes — all live on the canvas.
◎
Live Expected Value
Every change instantly recalculates probability-weighted NPV across all paths. The root EV updates in real time.
◆
Optimal Path Highlighting
The highest expected value path is automatically traced in gold — so you always know where the analysis points.
⟁
Sensitivity Analysis
Sweep any probability from 0–100% with a slider. Watch the Expected Value shift live. Understand your key risk drivers instantly.
◈
Full Style Control
Colours, node shapes, line weights, highlight colours. Every visual element is configurable to match your brand or client presentation.
↗
Export to PNG · PDF · SVG Pro
Export clean PNG snapshots free. Pro users unlock pixel-perfect PDF and fully editable SVG for presentations and reports.
Workflow

From decision to
insight in minutes.

01
Define your root decision
Click "New Tree" and name your starting decision point — whether it's a bid decision, investment thesis, project gate, or M&A go/no-go.
02
Branch into scenarios
Add child nodes for each possible outcome. Assign probabilities that reflect your analysis. Nest as many levels deep as your decision requires.
03
Enter NPV or value at terminals
At each leaf node, input the expected NPV, IRR, or any financial metric. Choose your currency. Arbor handles the rest.
04
Read the result — and stress test it
The tree instantly shows probability-weighted EV at root, highlights the best path, and lets you sweep any assumption with the sensitivity slider to see what moves the needle.
